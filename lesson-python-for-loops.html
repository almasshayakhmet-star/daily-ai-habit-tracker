🎯 1. НЕГІЗГІ ҚҰЗЫРЕТ

Алгоритмдік ойлау және бағдарламалау дағдыларын қолдану арқылы мәселелерді шешу.

📈 2. ОҚУ НӘТИЖЕСІ

Оқушы бағдарламалау құрылымдарын пайдаланып, есептерді шешеді және қарапайым бағдарламалар жасайды.

📖 3. ОҚУ МАҚСАТЫ

for циклінің құрылымын түсіндіреді және оны есептерді шешуде қолданады.

📋 4. САБАҚ МАҚСАТЫ
  • for циклінің синтаксисін сипаттайды;
  • for циклін қолданып бағдарлама жасайды;
  • циклдің жұмыс нәтижесін талдайды;
  • есептерді цикл арқылы шешеді.
💻 5. ТАПСЫРМА

Практикалық тапсырма (деңгейлік):

1-деңгей (бастапқы) 2-деңгей (орташа) 3-деңгей (жоғары)
1-деңгей (бастапқы)

1-ден 10-ға дейінгі сандарды экранға шығаратын бағдарлама жазыңыз. 

for i in range(1, 11):
    print(i)
2-деңгей (орташа)

1-ден n-ге дейінгі сандардың қосындысын есептейтін бағдарлама жазыңыз (n пайдаланушы енгізеді). 

n = int(input("n мәнін енгізіңіз: "))
s = 0
for i in range(1, n+1):
    s += i
print("Қосынды:", s)
3-деңгей (жоғары)

Берілген n санына дейінгі барлық жай сандарды шығаратын бағдарлама жазыңыз. 

n = int(input("n мәнін енгізіңіз: "))
for i in range(2, n+1):
    bolgyshtar = 0
    for j in range(2, i):
        if i % j == 0:
            bolgyshtar = 1
            break
    if bolgyshtar == 0:
        print(i)
🏅 6. БАҒАЛАУ КРИТЕРИЙІ

  • Циклді дұрыс қолданады.
  • Есептің шартын дұрыс түсінеді.
  • Нәтижені дұрыс шығарады.
  • Кодты тиімді және дұрыс құрастырады.
