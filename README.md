## 4. Сабақ мақсаты

- Қарапайым практикалық есептерді кодпен шешеді.

## 5. Тапсырмалар (деңгейлік)

### 1-деңгей (бастапқы)
**Тапсырма:** Пайдаланушы енгізген санның жұп не тақ екенін шығару.  
**Күтілетін әрекет:** `if` арқылы тексеру.

```python
try:
    n = int(input("Сан енгізіңіз: "))
    if n % 2 == 0:
        print("Жұп сан")
    else:
        print("Тақ сан")
except ValueError:
    print("Қате: бүтін сан енгізу керек")
```

### 2-деңгей (орташа)
**Тапсырма:** Оқушының ұпайын енгізіп, баға шығару:  
90–100 → “5”, 70–89 → “4”, 50–69 → “3”, 0–49 → “2”.  
**Күтілетін әрекет:** `if-elif-else` тізбегі.

```python
try:
    score = int(input("Ұпайды енгізіңіз (0-100): "))
    if not (0 <= score <= 100):
        print("Қате: ұпай 0-100 аралығында болуы керек")
    elif 90 <= score <= 100:
        print("Баға: 5")
    elif 70 <= score <= 89:
        print("Баға: 4")
    elif 50 <= score <= 69:
        print("Баға: 3")
    else:
        print("Баға: 2")
except ValueError:
    print("Қате: бүтін сан енгізу керек")
```

### 3-деңгей (жоғары)
**Тапсырма:** Екі сан және амал таңбасы (`+`, `-`, `*`, `/`) беріледі. Калькулятор нәтижесін шығару.  
**Қосымша шарт:** бөлу кезінде 0-ге бөлуді өңдеу.

```python
try:
    a = float(input("Бірінші сан: "))
    b = float(input("Екінші сан: "))
    op = input("Амал (+, -, *, /): ")

    if op == "+":
        print("Нәтиже:", a + b)
    elif op == "-":
        print("Нәтиже:", a - b)
    elif op == "*":
        print("Нәтиже:", a * b)
    elif op == "/":
        if b == 0:
            print("Қате: 0-ге бөлуге болмайды")
        else:
            print("Нәтиже:", a / b)
    else:
        print("Қате: амал таңбасы дұрыс емес")
except ValueError:
    print("Қате: санды дұрыс форматта енгізіңіз")
```
