🎯1. НЕГІЗГІ ҚҰЗЫРЕТ

Оқушылар алгоритмдік ойлау дағдыларын дамытып, Python бағдарламалау тілінде шартты операторларды қолдану арқылы есептер шығарады.

📈2. ОҚУ НӘТИЖЕСІ
  • Python тіліндегі if операторын қолданады;
  • шарттарды дұрыс құрастырады;
  • қарапайым бағдарламалар жазады;
  • логикалық ойлау қабілеті дамиды.
📖3. ОҚУ МАҚСАТЫ

6.3.1.1 – Python бағдарламалау тілінде шартты операторларды қолданып есептер шығару.

📋4. САБАҚ МАҚСАТЫ
  • if операторының синтаксисін түсіндіреді;
  • шарттарды салыстыру операторларымен құрастырады;
  • Python бағдарламасында if операторын қолданады;
  • есептердің нәтижесін талдайды.
💻5. ТАПСЫРМАЛАР

Практикалық тапсырма (деңгейлік):

1-деңгей: шартты операторды тап 2-деңгей: қатені тауып, түзету енгіз 3-деңгей: үш санның ең үлкенін табу
1-деңгей (бастапқы)

Шартты операторды тап және бос орынды дұрыс сөзбен толықтыр.

n = int(input('Сан енгізіңіз:'))
___ n > 0:
    print('Оң сан')
2-деңгей (орташа)

Жоғарыда берілген есеп бойынша қатені тауып, түзету енгіз.

n = int(input('Сан енгізіңіз:'))
if n > 0:
    print('Оң сан')
3-деңгей (жоғары)

Үш санның ең үлкенін табатын бағдарлама жазыңыз.

a = int(input('a = '))
b = int(input('b = '))
c = int(input('c = '))

max_num = a
if b > max_num:
    max_num = b
if c > max_num:
    max_num = c

print('Ең үлкен сан:', max_num)

  • Бағдарлама кодын қатесіз жазады.
  • Нәтижені дұрыс шығарады.
